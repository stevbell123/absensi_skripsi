4.1. Arsitektur dan Framework yang Digunakan

Server backend dibangun menggunakan bahasa pemrograman Python 3.10+ dengan kerangka kerja FastAPI berkecepatan tinggi berbasis Asynchronous Server Gateway Interface (ASGI). Kerangka kerja ini dipilih karena mendukung pemrograman asinkron (async/await) yang sangat efisien dalam menangani konkurensi request HTTP dari perangkat bergerak (Flutter).

Komponen kecerdasan buatan (AI) terbagi menjadi dua tahapan modular:

  1. Face Detection (Deteksi Wajah): Menggunakan Ultralytics YOLOv26n (rilis 2026), model generasi terbaru dengan arsitektur NMS-Free End-to-End yang meniadakan latensi komputasi Non-Maximum Suppression pada CPU server.
  2. Face Recognition (Pengenalan Wajah): Menggunakan DeepFace dengan backbone ArcFace, menghasilkan vektor representasi fitur wajah berdimensi 512 ($512\text{-dimensional embedding}$).

G. Preprocessing Citra: Koreksi EXIF & CLAHE (Baris 188–226)

def terapkan_clahe(gambar_rgb: np.ndarray, clip_limit=2.0, tile_grid=(8, 8)) -> np.ndarray:
    lab = cv2.cvtColor(gambar_rgb, cv2.COLOR_RGB2LAB)
    l, a, b = cv2.split(lab)
    clahe = cv2.createCLAHE(clipLimit=clip_limit, tileGridSize=tile_grid)
    l_clahe = clahe.apply(l)
    lab_clahe = cv2.merge((l_clahe, a, b))
    return cv2.cvtColor(lab_clahe, cv2.COLOR_LAB2RGB)

def perbaiki_orientasi_gambar(gambar_bytes: bytes, gunakan_clahe: bool = True) -> np.ndarray:
    pil_img = Image.open(io.BytesIO(gambar_bytes))
    pil_img = ImageOps.exif_transpose(pil_img)
    pil_img = pil_img.convert("RGB")
    gambar_rgb = np.array(pil_img)
    if gunakan_clahe:
        gambar_rgb = terapkan_clahe(gambar_rgb)
    return gambar_rgb

Penjelasan Ilmiah & Landasan Teori:

  1. Koreksi Orientasi Sensor (EXIF Transposition): Sensor giroskop kamera smartphone merekam orientasi pengambilan foto dalam tag metadata EXIF. Fungsi ImageOps.exif_transpose membaca tag ini dan memutar larik piksel secara fisik ke posisi tegak lurus (*upright*). Tanpa koreksi ini, citra yang dipotret vertikal (portrait) bisa terbaca horizontal (landscape) miring 90°, yang dapat menggagalkan ekstraksi landmark wajah.
  2. Peningkatan Kontras Adaptif Berbatas (CLAHE - Contrast Limited Adaptive Histogram Equalization):
    • Ruang Warna CIELAB: Citra RGB dikonversi ke ruang warna CIELAB yang memisahkan kanal luminansi atau tingkat kecerahan ($L$) dari kanal krominansi atau warna ($a$ dan $b$). CLAHE hanya diterapkan pada kanal $L$, sehingga kontras wajah meningkat tajam tanpa mengubah warna asli kulit siswa.
    • Grid Kontekstual ($8 \times 8$): Citra dibagi menjadi blok-blok kecil berukuran $8 \times 8$ piksel (*tiles*). Ekualisasi histogram dilakukan secara lokal di setiap blok, bukan global, sehingga wajah siswa di sudut ruangan yang gelap tetap terlihat jelas meskipun bagian jendela kelas sangat terang (*backlight*).
    • Clip Limit ($2.0$): Parameter batas kliping sebesar $2.0$ membatasi tinggi puncak histogram lokal. Bagian histogram yang melebihi batas dipotong dan didistribusikan merata ke bin lain, mencegah timbulnya *noise* artifisial atau bintik-bintik pada bayangan wajah.

H. Formulasi Matematika Cosine Similarity (Baris 192–200)

def hitung_cosine_similarity(vektor_a: np.ndarray, vektor_b: np.ndarray) -> float:
    dot_product = np.dot(vektor_a, vektor_b)
    norma_a = np.linalg.norm(vektor_a)
    norma_b = np.linalg.norm(vektor_b)
    if norma_a == 0 or norma_b == 0:
        return 0.0
    return float(dot_product / (norma_a * norma_b))

Rumus Matematika:

$$\text{Cosine Similarity} = \cos(\theta) = \frac{\mathbf{A} \cdot \mathbf{B}}{\|\mathbf{A}\|_2 \times \|\mathbf{B}\|_2} = \frac{\sum_{i=1}^{512} A_i B_i}{\sqrt{\sum_{i=1}^{512} A_i^2} \times \sqrt{\sum_{i=1}^{512} B_i^2}}$$

Nilai kemiripan berada pada rentang $-1.0$ hingga $+1.0$, di mana nilai $+1.0$ menunjukkan bahwa arah kedua vektor fitur wajah identik sempurna. Metrik ini jauh lebih unggul dibandingkan *Euclidean Distance* karena Cosine Similarity hanya mengukur sudut antar fitur wajah, sehingga kebal terhadap perbedaan intensitas cahaya ruangan (*illumination invariant*).

2. Bedah Detail Modul Edge AI (On-Device Flutter)

lib/core/ai/face_detector_service.dart

A. Kelas FaceDetectorService (Deteksi Wajah On-Device)

Tujuan: Mendeteksi letak wajah manusia pada frame kamera tanpa perlu mengirim gambar ke internet.

Fungsi-Fungsi Kunci:

  • FaceDetectorService() (Konstruktor): Menginisialisasi objek FaceDetector dari paket google_mlkit_face_detection dengan konfigurasi kecepatan tinggi: 
    final options = FaceDetectorOptions(
  enableContours: false,   // Mematikan kontur garis tepi wajah (menghemat memori)
  enableLandmarks: false,  // Mematikan titik detail bibir/mata (menghemat CPU hingga 50%)
  performanceMode: FaceDetectorMode.fast, // Mode fast ultra cepat (< 20 ms)
  minFaceSize: 0.1,        // Mampu mendeteksi wajah siswa dari jarak kelas normal
);
_faceDetector = FaceDetector(options: options);
  • Future<List<Face>> detectFaces(InputImage inputImage): Menerima citra frame kamera dan mengembalikan daftar objek Face yang berisi koordinat kotak pembatas (Bounding Box: left, top, right, bottom).
  • Future<List<Face>> detectFacesFromFile(String filePath): Pembungkus untuk memuat citra dari path file penyimpanan lokal sebelum diproses oleh detectFaces.
  • void dispose(): Menutup aliran resource detector agar tidak terjadi kebocoran memori (memory leak).
lib/core/ai/clahe_service.dart

B. Kelas ClaheService (Contrast Limited Adaptive Histogram Equalization)

Tujuan: Memperbaiki kontras citra wajah pada kondisi pencahayaan yang buruk (bayangan, backlight jendela, ruangan temaram) menggunakan implementasi murni bahasa Dart (Pure Dart) berkecepatan 3–5 milidetik.

Fungsi-Fungsi Kunci:

  • static img.Image applyClahe(img.Image src, {clipLimit = 2.0, gridSize = 8}): Fungsi utama pemroses citra wajah ukuran 112×112 piksel.
    1. Ekstraksi Kanal Luminansi Y (Formula Standar ITU-R BT.601): 
      final int yVal = (0.299 * pixel.r + 0.587 * pixel.g + 0.114 * pixel.b).round().clamp(0, 255);
      Alasan Ilmiah: CLAHE hanya dioperasikan pada komponen terang-gelap (Luminansi Y), bukan pada warna merah/hijau/biru (RGB). Ini menjamin rona warna kulit asli siswa tidak berubah dan tidak timbul artefak kemerahan.
    2. Pembagian Blok Kontekstual 8×8 (Grid Tiles): Citra dibagi menjadi 64 petak kecil berukuran 14×14 piksel agar perataan kontras bersifat lokal adaptif.
    3. Kliping Histogram & Redistribusi (Clip Limit = 2.0): 
      final int clipThreshold = max(1, (clipLimit * (tilePixelCount / 256)).round());
// Kelebihan piksel di atas ambang batas dipotong dan disebar merata ke 256 bin
      Mencegah peningkatan kontras berlebih (over-amplification) yang dapat memunculkan derau (noise).
    4. Interpolasi Bilinear 4 Tile: Menghitung nilai akhir piksel berdasarkan pembobotan jarak ke 4 pusat tile terdekat untuk menghilangkan garis batas petak (blocking artifacts).
lib/core/ai/face_embedding_service.dart

C. Kelas FaceEmbeddingService (Ekstraksi Fitur MobileFaceNet)

Tujuan: Mengubah potongan wajah 112×112 piksel menjadi vektor representasi biometrik 192 angka desimal (Feature Vector).

Fungsi-Fungsi Kunci:

  • Future<void> initialize(): Memuat model AI berformat assets/models/mobilefacenet.tflite ke memori menggunakan Interpreter.fromAsset().
  • img.Image cropAndAlignFace(img.Image fullImage, Rect boundingBox): 
    // Menambahkan margin 15% agar dagu dan kening tidak terpotong:
final double paddingX = boundingBox.width * 0.15;
final double paddingY = boundingBox.height * 0.15;
// Memotong citra dan me-resize presisi ke 112x112 piksel
  • List<double> extractEmbedding(img.Image faceImage, {bool applyClahe = true}):
    1. Menerapkan ClaheService.applyClahe() pada potongan 112×112 piksel.
    2. Normalisasi rentang piksel standar model MobileFaceNet: (pixel - 127.5) / 127.5 menghasilkan rentang [-1.0, 1.0].
    3. Membentuk tensor input berdimensi [1, 112, 112, 3] tipe Float32List.
    4. Menjalankan inferensi model: _interpreter.run(input, output) menghasilkan 192 angka float.
    5. L2 Normalization (Unit Vector Hypersphere): 
      double norm = sqrt(sum(embedding[i] * embedding[i]));
embedding[i] = embedding[i] / norm; // Panjang vektor tepat 1.0
lib/core/ai/face_matching_service.dart

D. Kelas FaceMatchingService (Verifikasi & Pencocokan Wajah)

Tujuan: Membandingkan vektor wajah yang baru tertangkap kamera dengan seluruh data vektor siswa yang ada di database.

Konstanta & Parameter Ambang Batas:

  • static const double batasTerima = 1.0;: Ambang batas jarak Euclidean maksimum. Karena vektor telah ternormalisasi L2, jarak 0.0 berarti 100% identik, dan jarak ≤ 1.0 dikategorikan sebagai orang yang sama.
  • static const double selisihMinimal = 0.06;: Ambang batas selisih kandidat terbaik ke-1 vs ke-2 (Margin Verification). Mencegah salah presensi jika ada dua siswa yang memiliki kemiripan wajah tinggi.

Fungsi-Fungsi Kunci:

  • static double euclideanDistance(List<double> a, List<double> b): Menghitung jarak geometris ruang Euclidean: d = √( Σ (a[i] - b[i])² ).
  • static double cosineSimilarity(List<double> a, List<double> b): Menghitung kosinus sudut antar-dua vektor: cos(θ) = (a · b) / (||a|| ||b||).
  • List<MatchResult> matchFaces(List<List<double>> embeddings, List<List<int>> boxes): Melakukan iterasi seluruh wajah yang tertangkap kamera, mencari siswa dengan jarak Euclidean terkecil, memeriksa aturan selisihMinimal, dan memastikan penugasan unik (1 siswa tidak bisa diabsen dobel di frame yang sama).
lib/core/ai/face_database_service.dart

E. Kelas FaceDatabaseService (Sinkronisasi Offline-First)

Tujuan: Mengelola penyimpanan vektor biometrik siswa secara lokal di perangkat ponsel dan awan (Cloud).

Fungsi-Fungsi Kunci:

  • Future<void> saveEmbedding(nim, name, embedding): Menyimpan vektor 192 dimensi ke koleksi face_embeddings di Cloud Firestore dan memperbarui cache lokal Hive.
  • Future<List<FaceRecord>> syncByClass(String classId): Mengunduh data biometrik seluruh siswa dalam kelas tertentu dari Firestore lalu menyimpannya ke Hive DB di penyimpanan internal ponsel.
  • Future<List<FaceRecord>> loadFromLocal(): Membaca data siswa langsung dari memori lokal Hive. Memungkinkan absensi berjalan **100% tanpa internet (Offline)**.

3. Bedah Detail Modul Antarmuka Kamera & Presensi (UI)

lib/features/attendance/presentation/AttendanceScreen.dart

A. Layar Kamera Presensi Cerdas (AttendanceScreen)

Tujuan: Mengelola pratinjau kamera langsung (Live Camera Preview), menjalankan loop pemindaian otomatis, memberikan umpan balik visual & getaran, dan menyediakan saklar pemilihan mesin (Dual-Engine Switch).

Variabel & State Kunci:

  • bool _useServerEngine: Saklar logika. Bernilai false untuk Mode ⚡ On-Device + CLAHE, dan true untuk Mode 🌐 Server YOLOv26.
  • bool _isAutoScan: Menentukan apakah pemindaian berjalan kontinu otomatis atau dijeda.
  • Timer? _autoScanTimer: Pewaktu periodik pemicu pemrosesan frame kamera.

Fungsi-Fungsi Kunci:

  • void _startContinuousAutoScan(): Mengatur kecepatan siklus pemindaian secara adaptif: 
    // On-Device sangat cepat (600 ms), Server diberi jeda 1400 ms agar jaringan 4G stabil
final int intervalMs = _useServerEngine ? 1400 : 600;
_autoScanTimer = Timer.periodic(Duration(milliseconds: intervalMs), (timer) {
  if (!_isScanningCycle && _isAiReady && mounted) {
    _runAutoScanCycle();
  }
});
  • Future<void> _runAutoScanCycle(): Fungsi orkestrator utama:
    1. Memanggil _controller.takePicture() untuk menangkap frame kamera.
    2. Jika _useServerEngine == true, memanggil _runServerScan(picture.path).
    3. Jika _useServerEngine == false:
      • Menjalankan _detectorService.detectFaces().
      • Mengekstrak embedding via _embeddingService.extractEmbedding().
      • Mencocokkan via _matchingService.matchFaces().
      • Jika siswa cocok: memperbarui status AttendanceStatus.hadir, menggetarkan ponsel (HapticFeedback.mediumImpact()), dan menampilkan pop-up hijau 🎉 [Nama Siswa] (Hadir)!.
    4. Pembersihan Cache File Foto Otomatis: 
      try {
  final f = File(picture.path);
  if (await f.exists()) await f.delete(); // Menghapus file foto agar penyimpanan ponsel tidak penuh
} catch (_) {}
  • Future<void> _runServerScan(String filePath): Melakukan kompresi citra ke 1280px (~85 KB) menggunakan pustaka image, lalu mengirimkannya via HTTP POST Multipart ke alamat IP VPS (http://103.175.206.22:8001/api/scan-attendance).
  • Widget build(BuildContext context): Menyusun tampilan antarmuka:
    • Layar Kamera Penuh (Full Viewport): Bebas dari tombol yang melayang di tengah layar agar sudut pandang luas dan seragam/baju siswa tidak menghalangi deteksi.
    • Panel Kontrol Bawah (bottomNavigationBar): Menampung saklar mode mesin, ringkasan kehadiran siswa, tombol jeda/lanjut, dan tombol selesai absensi.

4. Bedah Detail Modul Server AI Cloud (FastAPI + YOLOv26)

server_guru/main.py

A. Server AI Terpusat (server_guru/main.py)

Tujuan: Menjalankan pemrosesan citra tingkat lanjut di server VPS Ubuntu untuk absensi rombongan 5–6 siswa sekaligus dalam satu jepretan kamera.

Fungsi-Fungsi Kunci:

  • perbaiki_orientasi_gambar(gambar_bytes): Membaca tag EXIF kamera ponsel, mengoreksi rotasi foto (portrait/landscape), me-resize ukuran maksimum ke 1280 piksel, dan mengaplikasikan CLAHE pada kanal L (CIELAB).
  • terapkan_clahe(gambar_rgb): Mengubah ruang warna RGB ke CIELAB, lalu menerapkan algoritma OpenCV: 
    clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
l_clahe = clahe.apply(l)
# Menggabungkan kembali L hasil CLAHE dengan kanal a dan b asli
  • deteksi_dan_crop_wajah(gambar_rgb): Menggunakan model Ultralytics YOLOv26 (yolo26n.pt) dengan ambang keyakinan YOLO_CONFIDENCE = 0.25 untuk mendeteksi seluruh koordinat wajah siswa di dalam foto secara simultan.
  • ekstrak_embedding_tflite(gambar_wajah): Me-resize potongan wajah menggunakan interpolasi Lanczos4 (cv2.INTER_LANCZOS4) ke 112×112 piksel, normalisasi (pixel - 127.5) / 128.0, dan mengeksekusi MobileFaceNet TFLite pada CPU VPS untuk menghasilkan vektor 192 dimensi.
  • cocokkan_dengan_kelas(vektor_wajah, class_id): Algoritma pencocokan Cosine Similarity: 
    COSINE_THRESHOLD = 0.28  # Ambang batas penerimaan kehadiran
SELISIH_MINIMAL = 0.06   # Proteksi selisih juara 1 vs juara 2 (Anti-Salah Orang)
  • simpan_absensi_firestore(siswa_dikenali): Menyimpan catatan kehadiran ke Firestore secara asinkron menggunakan asyncio.to_thread di background thread agar tidak menahan respon HTTP ke ponsel.
  • Endpoint @app.post("/api/scan-attendance"): Menerima unggahan foto absensi dari aplikasi ponsel dan mengembalikan respon JSON daftar siswa yang berhasil dikenali dalam waktu < 1 detik.

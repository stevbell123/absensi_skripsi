Topik Skripsi: Sistem Presensi Kehadiran Siswa Real-Time Multi-Wajah Berbasis On-Device Biometrics (Google ML Kit + MobileFaceNet) dan Cloud Synchronization (FastAPI + Firebase + Hive).

Komponen Lokasi Peran Utama Kelebihan untuk Skripsi

💡 Apakah Database Hive Membebani Smartphone?

Jawaban: SAMA SEKALI TIDAK MEMBEBANI HP.

Berikut pembuktian matematisnya:

  • 1 data vektor siswa = 128 angka desimal Float32 = 512 byte (sekitar 0,5 KB).
  • Data 1 kelas (30 siswa) = 30 × 0,5 KB = 15 KB (0,015 MB).
  • Data 1 angkatan (180 siswa) = 180 × 0,5 KB = ± 90 KB (0,09 MB).

Perbandingan Nyata: Satu file foto WhatsApp berukuran sekitar 3.000 KB. Data 180 siswa di Hive hanya berukuran 90 KB (30 kali lebih ringan dari satu lembar foto). Oleh karena itu, beban memori Hive hampir 0% dan justru menghemat baterai HP karena tidak perlu terus mengunduh data dari internet.

BAB III: PENJELASAN KODE PROGRAM

1. Backend Python (`server_guru/main.py`)

  • FastAPI + slowapi: Framework REST API asinkron dengan pembatas request @limiter.limit("30/minute") untuk mencegah serangan DDoS.
  • firebase_admin: Mengakses Cloud Firestore dengan kredensial root sehingga memiliki hak penuh mengelola data biometrik.
  • YOLOv26 / YOLOv8: Mendeteksi banyak wajah sekaligus dalam ruang kelas secara akurat dengan padding 15% agar kontur wajah utuh.
  • DeepFace (ArcFace 512-d): Menghasilkan representasi wajah 512 dimensi dengan metrik Cosine Similarity ambang COSINE_THRESHOLD = 0.80.
  • /force-backup & smtplib: Mencadangkan seluruh koleksi Firestore ke JSON otomatis dan mengirim email peringatan darurat jika server mengalami error.

2. Client Mobile (`Flutter`)

  • face_detector_service.dart: Membungkus Google ML Kit Face Detection untuk menemukan koordinat wajah di HP dalam waktu ~20 ms.
  • face_embedding_service.dart: Menjalankan model mobilefacenet.tflite untuk menghasilkan 128 dimensi embedding ternormalisasi L2.
  • face_matching_service.dart: Menghitung jarak Euclidean ($D < 0.45$) dengan pengamanan selisih minimal $0.06$ untuk menghindari kesalahan pada siswa berwajah mirip.
  • face_database_service.dart: Mengelola penyimpanan dua lapis (Hive Box offline + Firestore Cloud online).
  • RegisterStudentScreen.dart: Pendaftaran cerdas yang otomatis memilih wajah terbesar dan mengabaikan objek latar belakang.
  • AttendanceScreen.dart: Scanner otomatis real-time dengan animasi laser hijau, notifikasi pop-up kehadiran, dan getaran haptic.

Tips Sidang Skripsi: Bila penguji bertanya "Mengapa memakai arsitektur hybrid ini?", jawablah: "Arsitektur ini menggabungkan kecepatan inferensi lokal di HP (bebas internet dan latensi rendah) dengan keamanan pencadangan data serta pemantauan terpusat di Cloud Server."

💡 Apakah Database Hive Membebani HP? (Bukti Matematis untuk Sidang)

JAWABAN: SAMA SEKALI TIDAK MEMBEBANI HP.

  • Yang disimpan di Hive bukan file gambar/foto, melainkan hanya 128 angka desimal (Vektor Embedding).
  • 1 data siswa = 128 angka Float32 × 4 byte = 512 byte (± 0,5 KB).
  • Untuk 1 kelas (30 siswa) = 30 × 0,5 KB = 15 KB (0,015 MB).
  • Untuk 1 angkatan (180 siswa) = 180 × 0,5 KB = 90 KB (0,09 MB).

Perbandingan: 1 lembar foto kamera HP berukuran 3.000 KB (3 MB). Artinya data 180 siswa di Hive 30x lebih kecil dari 1 lembar foto biasa. HP sama sekali tidak berat, dan justru sangat menghemat kuota dan baterai!

BAB III: PENJELASAN KODE PROGRAM SECARA RINCI

1. Backend Python (`server_guru/main.py`)

  • FastAPI + slowapi: Framework server berkinerja tinggi dengan pembatas request @limiter.limit("30/minute") untuk mencegah serangan DDoS dan membatasi beban CPU VPS.
  • firebase_admin: Menghubungkan VPS ke Cloud Firestore menggunakan kredensial root Service Account (kebal penolakan Security Rules).
  • YOLOv26 / YOLOv8: Model deteksi objek wajah berkecepatan tinggi dengan padding 15% (FACE_PADDING = 0.15) untuk memotong wajah siswa secara utuh.
  • DeepFace (ArcFace): Mengekstrak fitur wajah menjadi vektor 512 dimensi dan mencocokkannya dengan metrik Cosine Similarity >= 0.80.
  • /force-backup & smtplib: Endpoint pencadangan otomatis seluruh database ke file JSON berstempel waktu serta pengirim email peringatan darurat jika server mengalami crash.

2. Client Mobile Flutter

  • face_detector_service.dart: Membungkus Google ML Kit Face Detection untuk mendeteksi koordinat wajah di HP dalam waktu ~20 ms menggunakan akselerasi GPU/NPU ponsel.
  • face_embedding_service.dart: Menjalankan model mobilefacenet.tflite untuk menghasilkan vektor 128 dimensi dengan normalisasi L2.
  • face_matching_service.dart: Menghitung jarak Euclidean ($D < 0.45$) dengan pengaman selisih minimal ($0.06$) agar identitas siswa tidak tertukar.
  • face_database_service.dart: Mengelola penyimpanan dua lapis (Hive Box offline + Firestore Cloud online).
  • RegisterStudentScreen.dart: Layar pendaftaran cerdas yang otomatis memilih wajah terbesar dan mengabaikan noise latar belakang, sehingga pengguna tidak perlu mendekatkan HP terlalu dekat.
  • AttendanceScreen.dart: Layar scanner otomatis real-time tanpa tombol jepret, dilengkapi garis animasi laser hijau, kotak bidik lebar 92%, dan notifikasi kehadiran instan.
